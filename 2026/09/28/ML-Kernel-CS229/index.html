Machine Learning-核方法(CS229)

发表于 2026-09-28 分类于 CS229 阅读次数：

Kernel Method

我们前面考虑的很多模型虽然在参数 \(\theta\) 上是线性的,但是这并不意味着模型关于输入特征 \(x\) 也必须是线性的.例如考虑一个一元多项式回归模型 \(h_{\theta}(x)=\theta_0+\theta_1x+\theta_2x^2+\theta_3x^3,\ x\in\mathbb{R}\).从输入 \(x\) 的角度来看,这个模型显然是非线性的,但是如果重新定义一个特征映射\(\phi(x)=\begin{pmatrix}1,x,x^2,x^3\end{pmatrix}^T:\mathbb{R}\rightarrow\mathbb{R}^4,\)那么原来的模型就可以重新写成 \(h_{\theta}(x)=\theta^T\phi(x)\).所以我们可以将 \(\phi(x)\) 看成对于原始特征 \(x\) 的一个新的表示.我们并不是直接在原来的输入空间中拟合一个非线性模型,而是先通过映射 \(\phi\) 将数据映射到一个新的高维特征空间中,然后在这个新的空间中使用一个线性模型.

因此对于原始样本 \((x^{(i)},y^{(i)})\),经过特征映射之后，我们实际上得到的是新的样本 \((\phi(x^{(i)}),y^{(i)})\).所以原来的非线性回归问题就转换成了高维特征空间中的线性回归问题.例如使用平方损失函数的时候,我们有 \[ J(\theta)=\frac{1}{2}\sum_{i=1}^{n} \left(y^{(i)}-\theta^T\phi(x^{(i)})\right)^2. \] 相应的梯度下降更新公式为 \[ \theta:=\theta+\alpha\sum_{i=1}^{n} \left(y^{(i)}-\theta^T\phi(x^{(i)})\right)\phi(x^{(i)}). \] 进一步考虑一般情况,假设原始样本 \(x\in\mathbb{R}^d\),并且定义一个特征映射 \(\phi:\mathbb{R}^d\rightarrow\mathbb{R}^p\),那么模型可以写成 \(h_{\theta}(x)=\theta^T\phi(x)\),其中 \(\theta\in\mathbb{R}^p\).这里的问题在于,如果我们希望通过高维特征表达比较复杂的非线性关系,那么 \(p\) 很可能会非常大.例如对于 \(x=(x_1,\dots,x_d)^T\),如果构造所有次数不超过3的多项式特征,那么特征数量会随着 \(d\) 很快增长,从渐近复杂度来看有 \(p=O(d^3)\).所以如果每一次都显式构造 \(\phi(x)\),那么一次计算 \(\theta^T\phi(x)\) 就需要 \(O(p)\) 的计算量,而使用整个样本集进行一次梯度更新则需要大约 \(O(np)\) 的计算量.当特征空间维度非常高的时候,这样的计算代价就会变得十分巨大.

Kernel Trick

这里我们可以观察前面的梯度下降更新公式,如果令初始参数 \(\theta^{(0)}=0\),那么每一次对于 \(\theta\) 的更新实际上都是若干个 \(\phi(x^{(i)})\) 的线性组合.因此无论进行多少次迭代,最终得到的参数向量一定可以表示成 \[ \theta=\sum_{i=1}^{n}\beta_i\phi(x^{(i)}), \] 其中 \(\beta=(\beta_1,\dots,\beta_n)^T\in\mathbb{R}^n\).也就是说,我们可以不再直接描述一个 \(p\) 维参数 \(\theta\),而是使用 \(n\) 个系数 \(\beta_i\) 来表示它.在 \(p\gg n\) 的情况下,这种表示尤其有用.将这个表示代入模型中,有 \[ h(x)=\theta^T\phi(x)=\left(\sum_{j=1}^{n}\beta_j\phi(x^{(j)})\right)^T\phi(x)=\sum_{j=1}^{n}\beta_j\left\langle\phi(x^{(j)}),\phi(x)\right\rangle. \] 所以我们发现,虽然模型工作在高维空间中,但是我们真正需要计算的并不是高维向量 \(\phi(x)\) 本身,而只是不同样本映射之后的内积 \(\langle\phi(x^{(i)}),\phi(x^{(j)})\rangle\).同样地,将 \(\theta=\sum_j\beta_j\phi(x^{(j)})\) 代入更新公式,可以得到 \[ \beta_i:=\beta_i+\alpha\left(y^{(i)}-\sum_{j=1}^{n}\beta_j\left\langle\phi(x^{(j)}),\phi(x^{(i)})\right\rangle\right). \] 所以整个算法需要用到的关于高维特征的信息,实际上都只通过特征向量之间的内积出现.这里就引出了 Kernel Method 的核心思想.我们定义 \(K(x,z)=\left\langle\phi(x),\phi(z)\right\rangle,\)并称 \(K\) 为 kernel function.如果我们能够直接计算 \(K(x,z)\),那么就没有必要显式计算高维映射 \(\phi(x)\).

为了方便说明,我们考虑特征映射 \(\phi(x)=(1,x,x^{\otimes 2},x^{\otimes 3})^T\),其中 \(x^{\otimes 2}\) 和 \(x^{\otimes 3}\) 分别表示二阶和三阶张量积特征.那么对于两个样本 \(x,z\),有 \[ \left\langle\phi(x),\phi(z)\right\rangle = 1+\langle x,z\rangle+\langle x,z\rangle^2+\langle x,z\rangle^3. \] 虽然对应的显式特征空间维度可以达到 \(O(d^3)\),但是我们实际上只需要首先计算 \(\langle x,z\rangle\),这个计算的复杂度只有 \(O(d)\),然后再计算这个标量的平方和立方即可.所以我们并不需要真的将一个 \(d\) 维向量映射到一个 \(O(d^3)\) 维空间中.这就是所谓的 kernel trick：如果某个算法中对于特征映射 \(\phi(x)\) 的使用始终只通过 \(\langle\phi(x),\phi(z)\rangle\) 出现,那么我们就可以寻找一个 kernel function \(K(x,z)=\langle\phi(x),\phi(z)\rangle\),直接计算这个内积,从而避免显式构造高维特征.

Kernel Method for Regression

以前面的回归问题为例,我们首先计算训练样本之间的 kernel matrix,其中 \(K_{ij}=K(x^{(i)},x^{(j)})\).模型在训练样本 \(x^{(i)}\) 上的输出为 \[ h(x^{(i)})=\sum_{j=1}^{n}\beta_jK(x^{(j)},x^{(i)}). \] 因此相应的更新公式可以写成 \[ \beta_i:=\beta_i+\alpha\left( y^{(i)}-\sum_{j=1}^{n}\beta_jK(x^{(j)},x^{(i)}) \right). \] 所以一旦 kernel matrix 被提前计算出来,后面的优化过程就完全不需要知道 \(\phi(x)\) 的具体形式.对于一个新的样本 \(x\),模型的预测结果为 \(h(x)=\sum_{i=1}^{n}\beta_iK(x^{(i)},x)\).因此无论是在训练阶段还是预测阶段,我们都可以完全绕过显式的高维特征映射.

不过需要注意的是,Kernel Method 并不意味着计算一定会变得非常便宜.因为 kernel matrix 是一个 \(n\times n\) 的矩阵,所以存储它需要 \(O(n^2)\) 的空间,而直接使用完整 kernel matrix 进行计算时,也经常会带来 \(O(n^2)\) 甚至更高的计算复杂度.因此 Kernel Method 主要解决的是特征维度 \(p\) 很大的问题；如果样本数量 \(n\) 本身非常大,那么仍然可能出现计算瓶颈.

Kernel Design

从前面的分析中可以发现,如果我们已经给定了一个特征映射 \(\phi\),那么自然可以定义 \(K(x,z)=\langle\phi(x),\phi(z)\rangle\).但是 Kernel Method 更有意思的地方在于,我们很多时候甚至不需要先设计 \(\phi\),而是可以直接设计 kernel function \(K\).从直观角度来看,kernel function 可以理解为高维特征空间中的一种 similarity measure.如果两个样本在我们关心的意义下比较相似,那么希望 \(K(x,z)\) 比较大；如果两个样本差异很大,那么希望 kernel 值比较小.

因此在实际问题中,我们可以结合领域知识直接设计一个能够描述样本相似程度的 kernel.也就是说,原来的问题从 design a good feature map \(\phi\),转换成了 design a good kernel \(K\).但是这里马上会产生一个新的问题：是不是任意一个用于衡量相似性的函数 \(K(x,z)\),都能够被写成 \(K(x,z)=\langle\phi(x),\phi(z)\rangle\) 的形式？答案是否定的.如果希望一个函数能够作为合法的 kernel function,那么它必须满足一定的条件.

给定训练样本 \(x^{(1)},x^{(2)},\dots,x^{(n)}\),定义相应的 kernel matrix \(K\in\mathbb{R}^{n\times n}\),其中 \(K_{ij}=K(x^{(i)},x^{(j)})\).如果 \(K\) 确实来自某个特征映射 \(K(x,z)=\langle\phi(x),\phi(z)\rangle\),那么对于任意向量 \(c\in\mathbb{R}^n\),都有 \[ c^TKc=\sum_{i=1}^{n}\sum_{j=1}^{n}c_ic_jK(x^{(i)},x^{(j)})=\sum_{i=1}^{n}\sum_{j=1}^{n} c_ic_j\left\langle\phi(x^{(i)}),\phi(x^{(j)})\right\rangle=\left\|\sum_{i=1}^{n}c_i\phi(x^{(i)})\right\|^2\geq0. \] 因此一个合法 kernel 对应的 kernel matrix 一定是 positive semi-definite 的,也就是 \(K\succeq0\).换句话说,对于任意有限个样本 \(x^{(1)},\dots,x^{(n)}\),由 \(K_{ij}=K(x^{(i)},x^{(j)})\) 构成的 Gram matrix 都应当是对称半正定矩阵.所以我们并不一定需要真的知道隐藏在 kernel 背后的 \(\phi\) 究竟是什么.只要能够证明对于任意有限样本集,对应的 kernel matrix 都是 positive semi-definite 的,那么这个 \(K\) 就可以合法地用于 Kernel Method.

Polynomial Kernel

一个非常常见的 kernel 是\(K(x,z)=(x^Tz+c)^k,\)其中通常取 \(c\geq0\),\(k\in\mathbb{N}\).这个 kernel 对应于某个有限维的多项式特征空间.因此我们前面讨论的多项式特征映射,实际上可以直接通过 Polynomial Kernel 实现,而不需要真的构造全部多项式特征.

Gaussian Kernel / RBF Kernel

另一个非常重要的 kernel 是 Gaussian Kernel,也称为 RBF Kernel,\(K(x,z)=\exp\left(-\frac{\|x-z\|^2}{2\sigma^2}\right).\)这里的 \(\sigma\) 控制 kernel 随着样本距离增加而衰减的速度.当 \(x\) 和 \(z\) 非常接近的时候,\(K(x,z)\approx1\)；而当两者距离非常大的时候,\(K(x,z)\approx0\).因此 Gaussian Kernel 很自然地表达了样本之间的局部相似性.与 Polynomial Kernel 不同,Gaussian Kernel 所隐含的特征空间可以看成是无限维的.但是借助 kernel trick,我们仍然只需要计算标量函数 \(K(x,z)\),完全没有必要显式构造这个无限维的特征向量.这也进一步体现了 Kernel Method 的核心优势：我们可以在一个极高维甚至无限维的特征空间中进行线性学习,同时不需要真的显式进入这个高维空间.
